## 当前技术栈

- Android: Kotlin + Jetpack Compose
- Backend: Spring Boot + Java 17
- Database: PostgreSQL
- Cache: Redis
- Message Queue: Kafka
- Realtime: WebSocket
- Container: Docker Compose

## 项目目标

通过完整实现一个生产级聊天协作系统，沉淀：

- Spring Boot 企业级后端能力
- DDD领域建模能力
- Event Driven Architecture设计能力
- Kafka消息系统实践
- WebSocket实时通信实践
- Android客户端开发能力
- Docker与CI/CD工程能力
